# M3Nverse
Official repository for M3Nverse... a Web3 Learn2Earn and NFT ecosystem powered by the $M3N token on BNB Chain.
🪙 M3Nverse — Empowering Web3 Learning & Earning

M3Nverse is a decentralized Learn2Earn ecosystem built on BNB Smart Chain (BEP-20).
Our mission is to make Web3 education accessible, practical, and rewarding for users worldwide — powered by the $M3N token.

🚀 Overview

M3Nverse enables users to learn blockchain concepts, earn crypto rewards, and participate in verified Web3 projects.
By combining education, NFTs, and community-driven incentives, it bridges the gap between Web2 learners and the Web3 economy.

🧩 Core Features

🎓 Learn2Earn Hub: Users complete short blockchain learning challenges and earn $M3N rewards.

🖼️ NFT Lounge: A gas-free NFT marketplace supporting new creators.

🚀 Micro Launchpad: Supports verified mini-projects and creators with exposure and funding.

🗳️ Governance & Staking: Token holders can stake and vote on community initiatives.

🔧 Technical Details

Network: BNB Smart Chain (Testnet)

Token Standard: BEP-20

Smart Contract: M3NverseToken.sol

Compiler: Solidity 0.8.x

Status: Testnet-ready, verified and optimized for audit.
